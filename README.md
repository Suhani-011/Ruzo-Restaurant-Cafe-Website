
# Ruzo Restaurant & Cafe Website

A responsive restaurant and cafe website developed as a frontend web development project. Ruzo provides an attractive online presence for a restaurant, showcasing its food menu, services, special offers, table reservation section, and contact information.

## Live Demo

https://suhani-011.github.io/Ruzo-Restaurant-Cafe-Website/

## Features

- **Home & Navigation:** Clean navigation menu for easy browsing.
- **About Us:** Introduction to the restaurant and its services.
- **Our Services:** Sections highlighting restaurant services and special offerings.
- **Food Menu:** Displays food items with images, names, and pricing.
- **Special Offers:** Highlights featured food items and promotional offers.
- **Table Reservation:** Reservation form interface for booking a table.
- **Restaurant Information:** Displays restaurant location and contact details.
- **Blog Section:** Showcases food-related articles and updates.
- **Responsive Design:** Layout designed to work across different screen sizes.

## Technologies Used

- HTML5 – Website structure.
- CSS3 – Styling and visual design.
- Bootstrap – Responsive layout and components.
- JavaScript – Interactive functionality.
- jQuery – DOM manipulation and interactive elements.

## Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/Suhani-011/Ruzo-Restaurant-Cafe-Website.git
```

### 2. Open the Project

Navigate to the project folder:

```bash
cd Ruzo-Restaurant-Cafe-Website
```

### 3. Run the Website

Open `index.html` in your browser.

You can also use the Live Server extension in VS Code to preview the website locally.
